# Quiz Matematika Kelas 4 SD

Aplikasi kuis interaktif untuk materi:

1. Nilai tempat bilangan cacah sampai 10.000
2. Operasi hitung bilangan cacah sampai 10.000
3. Perkalian dan pembagian bilangan cacah (3 angka dengan 1 angka)
4. Kelipatan dan faktor

## Cara menjalankan

1. Buka folder proyek.
2. Jalankan server lokal dengan perintah:

```bash
python -m http.server 8000
```

3. Buka browser ke:

```text
http://localhost:8000
```

## Struktur file

- `index.html` - tampilan halaman utama
- `style.css` - desain tampilan
- `script.js` - logika soal, skor, dan materi

## Fitur

- Pilihan materi kuis
- Soal acak dari setiap bab
- Skor otomatis
- Tampilan hasil akhir
- Responsif untuk desktop dan ponsel
